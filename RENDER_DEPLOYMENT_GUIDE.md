# Render Deployment Guide for POS Offline System

This guide walks you through deploying your POS Offline system to Render with Postgres database and Transak webhook integration.

## Prerequisites

1. **Render Account** - Create one at https://render.com
2. **GitHub Repository** - Your code must be pushed to GitHub
3. **Transak Credentials**:
   - Partner Access Token (from Transak dashboard)
   - API Key (for Transak API calls)

## Step 1: Prepare Your Repository

1. Ensure all changes are committed:
```bash
cd "C:\POS OFFLINE SFTWR"
git add .
git commit -m "Prepare for Render deployment"
git push origin main
```

2. Check that these files exist and are correct:
   - `render.yaml` (deployment config)
   - `backend/src/routes/transak.ts` (webhook endpoint)
   - `Dockerfile` (Docker config)
   - `backend/package.json` (dependencies)

## Step 2: Connect GitHub to Render

1. Go to https://dashboard.render.com
2. Click "New +" > "Blueprint"
3. Select "Public Git Repository"
4. Paste your GitHub repo URL: `https://github.com/YOUR_ORG/YOUR_REPO.git`
5. Click "Connect"

## Step 3: Configure Services

Render will auto-detect `render.yaml` and show:
- **pos-offline-api** (Web service - Node backend)
- **pos-postgres** (Postgres database)

Verify settings:
- Plan: Starter (free tier) or higher
- Region: Frankfurt (or your preference)
- Branch: main

## Step 4: Set Environment Variables

1. In Render dashboard, go to the **pos-offline-api** service
2. Click "Environment" tab
3. Add these secrets (do NOT commit to repo):
   - `PARTNER_ACCESS_TOKEN` = your Transak Partner Access Token
   - `TRANSAK_API_KEY` = your Transak API Key
   - `JWT_SECRET` = auto-generated by Render (already set)
   - `WEBHOOK_SECRET` = auto-generated by Render (already set)

## Step 5: Deploy

1. Click "Deploy" on the pos-offline-api service
2. Wait for build to complete (5-10 minutes)
3. Once live, you'll get a URL like: `https://pos-offline-api.onrender.com`

## Step 6: Initialize Database

After deployment, run the migrations to create tables:

1. Open terminal with access to psql
2. Get your Postgres connection string from Render dashboard:
   - Go to pos-postgres service > "Info" tab
   - Copy the "External Database URL"

3. Run migrations:
```bash
psql -d "postgres://user:password@host:5432/database" -f backend/migrations/0001_create_transak_vba_schema.sql
psql -d "postgres://user:password@host:5432/database" -f backend/migrations/0002_seed_transak_sample_data.sql
```

## Step 7: Configure Transak Webhook

1. Go to https://dashboard.transak.com
2. Webhook settings > Add webhook URL
3. Use: `https://pos-offline-api.onrender.com/webhooks/transak`
4. Environment: Production
5. Test webhook delivery

## Step 8: Test the Deployment

1. Health check:
```bash
curl https://pos-offline-api.onrender.com/health
```

Expected response:
```json
{"status":"ok","service":"transak-webhook"}
```

2. Get reconciliation report:
```bash
curl https://pos-offline-api.onrender.com/api/v1/reconciliation/report
```

3. Check Transak webhooks in Render logs:
   - Go to service > "Logs" tab
   - Search for "webhook" or "processed"

## Step 9: Deploy the Android App

1. Build the signed APK locally (see FLUTTER_BUILD_GUIDE.md)
2. Create a GitHub Release:
   - Go to your repo > Releases
   - Create new release
   - Upload the APK file
   - Users can download directly from GitHub

Or upload to:
- Google Play Store (requires account)
- Firebase App Distribution
- Your own CDN / web server

## Monitoring & Maintenance

### View Logs
```bash
Render Dashboard > pos-offline-api > Logs
```

### Database Backups
- Render auto-backs up Postgres
- Manual backups: use `pg_dump`
- Download from Render > pos-postgres > Backups

### Update Secrets
If you rotate Transak keys:
1. Render Dashboard > pos-offline-api > Environment
2. Update PARTNER_ACCESS_TOKEN
3. Service auto-restarts with new secrets

### Scaling
- Increase instance type for higher traffic
- Add read replicas to Postgres if needed

## Troubleshooting

### Build Fails
- Check logs: `Render > Build Logs`
- Ensure all dependencies in `backend/package.json`
- Verify `backend/dist/server.js` can be executed

### Postgres Connection Error
- Verify DATABASE_URL is set correctly
- Check connection string format: `postgres://user:pass@host:port/db`
- Allow Render service IP in Postgres firewall

### Webhook Not Received
- Check Render logs for HTTP 200 response
- Verify Transak webhook is configured with correct URL
- Test with curl or Postman

### APK Installation Issues
- Check that APK is signed with pos_release keystore
- Verify key.properties path is correct
- Use `flutter build apk --release` to rebuild

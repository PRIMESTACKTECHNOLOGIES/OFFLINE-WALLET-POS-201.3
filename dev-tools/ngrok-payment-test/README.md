Ngrok Payment Test
===================

Purpose
-------
A minimal Express server + static test page to validate Web Crypto API availability from a real device using an HTTPS URL via ngrok.

Files
-----
- server.js — Express server serving index.html and a simple /callback endpoint
- index.html — test page that checks window.isSecureContext and window.crypto.subtle
- package.json — minimal package.json with express dependency

Quick start
-----------
1. Install Node (recommended v14+).
2. Open a terminal in this folder:

   cd "C:\POS OFFLINE SFTWR\dev-tools\ngrok-payment-test"

3. Install dependencies:

   npm install

4. Start the server:

   npm start

   The server listens on http://localhost:3000 and exposes / (test page) and /health and /callback

5. Expose with ngrok (in another terminal). If you haven't installed ngrok, get it from https://ngrok.com/

   ngrok http 3000 --host-header=localhost

   Copy the https:// URL shown by ngrok (e.g. https://abcd-1234.ngrok.io)

6. On your Android/iOS device, open the ngrok https URL in Chrome/Safari (or configure the APK to open it via Chrome Custom Tabs). The test page will show whether window.crypto.subtle and secure context are available.

Debugging on device
-------------------
- For Android: use chrome://inspect to remote-debug the WebView / Custom Tab. Open DevTools and check the Console for logs.
- Run these expressions in the page console to verify:

  window.isSecureContext
  !!window.crypto
  !!(window.crypto && window.crypto.subtle)

- If any are false, Web Crypto is not available in that environment. Opening the same ngrok HTTPS URL in a modern browser (Chrome) should show all true.

Notes & next steps
------------------
- If the HTTPS page shows Web Crypto available but the APK still fails, open the payment page using Chrome Custom Tabs (Android) or SFSafariViewController (iOS) instead of an embedded WebView.
- For production, host the payment pages on a public HTTPS domain and use one-time tokens / short-lived session IDs for payment initiation.
- If you need example code to open Chrome Custom Tabs and handle deep-link callbacks, ask and it will be provided.
